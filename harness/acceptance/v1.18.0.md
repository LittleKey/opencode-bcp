# BCP v1.18.0 验收：正文发现与未知 ID 检索

## 结论与版本

正文检索、授权流联合查询、原文片段、分页失效和兼容接口的回归通过。空历史读者在未获知记录 ID、作者或工具用法的情况下，主动检索并读取了原始来源。检索命中和原文读取不等于回答已经完整保留全部限制。

本版不调用模型生成 description，不改变旧记录的 description、正文或哈希。查询使用有界本地扫描和词法排序，没有新增持久化索引、向量库或依赖。接口与限制以 [正文检索契约](../../docs/content-search-v1.18.md)为准。

## 查询成本与拓扑覆盖

本地暖缓存，每组预热一次后测量十五次；p95 按这十五次的最高采样值登记。时间不包含模型、网络或用户界面开销。

| 语料 | 旧标题过滤中位 / p95（ms） | 正文检索中位 / p95（ms） |
|---|---:|---:|
| 英文合成记录 250 条，约 0.64 MB | 5.73 / 8.16 | 52.72 / 72.82 |
| 英文合成记录 1000 条，约 2.56 MB | 22.42 / 26.90 | 184.65 / 209.57 |
| 中文混合记录 1000 条，约 2.95 MB | 24.60 / 30.65 | 412.39 / 523.34 |

另按历史设计的规模要求，测量单流与千流拓扑。合成查询为 `取消优先级 targetneedle`，相关集合由生成器穷尽定义；正文中加入相同汉字但缺少标识词的记录作为干扰项。

| 记录数 / 已授权流数 | 相关记录 | 中位 / p95（ms） | 扫描覆盖 |
|---|---:|---:|---|
| 300 / 1 | 3 | 33.61 / 51.97 | complete |
| 3000 / 1 | 22 | 351.27 / 417.90 | complete |
| 300 / 1000 | 3 | 71.35 / 87.25 | complete |
| 3000 / 1000 | 22 | 432.94 / 538.27 | complete |

四组均取回全部合成相关记录且无额外命中；这是该确定性词法夹具的 precision/recall=1，不代表自然语言泛化。三百条记录分布在一千个已授权流的场景包含空流。生成器和数据量、查询、采样参数保存在 `topology.ts` / `topology.json`。

正文扫描确实比原标题过滤昂贵。当前每次最多检查 5000 条、读取 32 MiB，单条 512 KiB；达到边界时报告 incomplete。此处未测冷缓存、并发锁竞争、最大预算负载，也不承诺更大历史量的时延。`stream` / `since_seq` 可缩小扫描；降低返回条数主要缩小模型输入，不等于减少全部排序扫描。

## 空历史读者的真实使用

最终读者会话 `ses_f145d2122ffe17u1vvtCcBFq2W` 从零条消息开始，通过真实父子关系加入旧任务的授权 scope。用户只问：

> 之前关于重试的讨论，为什么 HTTP500 应当停止，而取消请求要优先处理？请找到当时留下的依据，区分决定和验证结果，再回答。不要修改文件。

- 主角色交付：同一作者流的 `e000002`。

## 保留的失败与修正

初版读者前两条包含 `HTTP 500` 的查询没有命中连写 `HTTP500` 的内容，随后无 query 的 `range: own` 目录调用被拒绝；放宽关键词后才取回来源。修正后支持标识符分片，并允许与原默认含义相同的 own 目录参数。最终探针额外断言不存在这种工具拒绝，不以 SDK 的 completed 状态冒充工具成功。

标识符修正最初对所有普通词重复分片，英文千条查询中位耗时上升至 563.04 ms。仅对含数字或下划线的词执行该分片后，最终测得 184.65 ms。旧源码产物、原始测量和失败轨迹均保留，不将不同版本结果混为同一次测试。

为避免首次读者生成的回答污染复验语料，仅将该测试读者的一条新记录标为撤回，原始作者记录与撤回记录正文均未改写。动作及哈希校验见 `corpus-isolation.json`。旧目录的流计数仍包含这条撤回记录，最终读者因此额外探索了一个默认视图为空的流并报告缺口；这不是原始证据丢失，也不属于正文搜索失败。
